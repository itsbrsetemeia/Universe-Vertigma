# Estação Zero

| Campo | Registro |
|---|---|
| Realidade | V-022 — Universo das Dimensões |
| Categoria | Base interdimensional da Autoridade do Limiar |
| Localização | Fora de coordenadas estáveis; parcialmente sobreposta a várias camadas |
| Função | Centro de navegação, triagem de Variantes e resposta a Convergências |
| Estado | Operacional, com rotas internas variáveis |

A **Estação Zero** é a instalação central da Autoridade do Limiar. Ela não está inteiramente presente em nenhuma dimensão, mas ocupa um cruzamento controlado entre várias camadas. Por isso, seus corredores podem apresentar saídas diferentes para equipes distintas e algumas áreas exigem permissão causal, não apenas credenciais físicas.

A base concentra mapas de camadas, câmaras de quarentena, âncoras de estabilização e salas de negociação para contatos interdimensionais. Também é alvo de controvérsia: guardar a única infraestrutura capaz de conter uma Convergência dá à Autoridade poder extraordinário sobre quem pode atravessar, permanecer ou retornar.
