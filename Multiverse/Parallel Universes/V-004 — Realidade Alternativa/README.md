# V-004 — Realidade Alternativa

> *"A história não mudou. Ela escolheu outro caminho."*

## Visão geral

| Campo | Registro canônico |
|---|---|
| Código multiversal | V-004 |
| Designação | Realidade Alternativa; Universo-Espelho Histórico |
| Natureza | Realidade paralela historicamente próxima do V-202, mas causalmente divergente |
| Eixo distintivo | Um Ponto de Divergência produziu séculos de consequências em cascata |
| Papel narrativo | Explorar escolha, acaso, identidade, memória histórica e destinos não vividos |
| Relação com V-202 | Cronologia comparativa, não versão superior, inferior ou “correta” da realidade |
| Estado da descoberta | A divergência é detectável para observadores multiversais, mas desconhecida por grande parte de seus habitantes |

O **V-004** é uma realidade paralela extremamente próxima do V-202 em seus fundamentos humanos, mas profundamente diferente em seu presente. A diferença não é uma inversão simples de moralidade, política ou poder. Ela nasceu de uma escolha aparentemente pequena, ocorrida em algum ponto de uma história antes semelhante, e foi ampliada por gerações de decisões, encontros, acidentes, guerras evitadas e consequências inesperadas.

Para quem vive no V-004, sua história nunca “mudou”. Ela sempre foi assim. Uma paz que o V-202 não conheceu, uma instituição que nunca foi criada, uma descoberta antecipada ou a sobrevivência de uma pessoa importante fazem parte de uma cronologia legítima. A existência do V-202 só se torna perturbadora quando revela que outra vida, outro mundo e outra versão de cada pessoa também poderiam ter existido.

## Ideia central

O V-004 pergunta: **“E se a história tivesse escolhido diferente?”** Sua resposta não é que um único caminho deveria vencer os demais. Ela mostra que toda realidade é feita de possibilidades que se tornaram pessoas, sociedades e memórias reais para quem vive dentro delas.
