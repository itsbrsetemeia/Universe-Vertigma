# A Dissonância

A Dissonância é a fraqueza estrutural dos Dilaceradores. Se os seis forem confrontados simultaneamente com memórias originais que não passaram pela edição de Akira, seus poderes entram em conflito.

Thaar'gon começa a deformar uma realidade que AmarØ tenta restaurar. Jameelah nega vibrações que Lil'IØth precisa usar para estabelecer vínculo. Boi'Zhorrus transforma a própria resistência em sofrimento, enquanto Akira tenta preservar uma lembrança que os outros recusam. O grupo deixa de ser uma cadeia de falhas e se torna um circuito fechado de contradições.

Equinox conhece essa fraqueza. Ele não os ataca primeiro com força, mas com memória. O risco é que restaurar o passado também possa restaurar o vínculo entre os seis, criando uma escolha: derrotá-los ou dar-lhes uma oportunidade de voltar a ser quem eram.
