# 🔮 Objetos Místicos

> *"Alguns objetos são ferramentas. Outros são lendas. Os Objetos Místicos de Vertigma mudaram o destino de civilizações, iniciaram guerras e desafiaram as leis da realidade."*

Bem-vindo ao diretório **Objetos Místicos** do universo **Vertigma**.

Esta pasta reúne todos os artefatos sobrenaturais, cósmicos, dimensionais e ancestrais existentes no universo. Cada objeto possui sua própria história, origem, propriedades e impacto na lore.

---

# 📖 O que são Objetos Místicos?

Objetos Místicos são artefatos únicos ou extremamente raros que carregam algum tipo de energia extraordinária.

Sua existência pode estar ligada a:

- Entidades Primordiais
- Magia
- Energia Cósmica
- Dimensões
- Civilizações Perdidas
- Deuses
- Ciência extremamente avançada
- Anomalias do Multiverso

Nem todo objeto concede poder.

Alguns podem selar entidades, alterar a realidade, controlar elementos, abrir portais ou até influenciar o destino do universo.

# 📜 Regras de Criação

Todo objeto criado deve possuir:

- Uma origem coerente.
- Um propósito narrativo.
- Funcionamento bem explicado.
- Limitações claras.
- Consequências para seu uso.
- Relação com outros elementos do universo.

Evite criar objetos "invencíveis" ou sem custo.

---

# 🔗 Conexões

Sempre que possível, cada objeto deve estar conectado a:

- Personagens
- Organizações
- Civilizações
- Eventos
- Locais
- Dimensões
- Entidades
- Outros artefatos

Nenhum objeto deve existir isoladamente.

---

# 🎯 Objetivo

Construir uma coleção de artefatos memoráveis que enriquecem a história do universo Vertigma, servindo como elementos centrais para conflitos, descobertas, mistérios e grandes eventos.

Cada objeto deve parecer uma peça importante da história do multiverso, e não apenas um item poderoso.
