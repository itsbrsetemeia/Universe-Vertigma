# Anti-Heróis do Universo Vertigma

Esta subcategoria contém personagens que utilizam métodos questionáveis, mas possuem motivações nobres. Eles operam na zona cinzenta entre o bem e o mal, frequentemente em oposição a instituições incapazes de responder a problemas reais.
