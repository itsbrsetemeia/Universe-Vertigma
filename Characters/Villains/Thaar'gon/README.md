# Thaar'gon — O Deformador

> **“Eu não quebrei a realidade. Eu apenas parei de fingir que ela era sólida.”**

| Campo | Registro |
|---|---|
| Nome original | Caio Almeida |
| Nome corrompido | Thaar'gon |
| Títulos | O Deformador; A Anomalia Ø; O Fim que Caminha; O Último Caio; O Arquiteto do Esquecimento |
| Categoria | Vilão multiversal; anomalia consciente |
| Realidade de origem | Universo Ø / D — Diálico |
| Idade biológica | 15 anos, congelada |
| Idade existencial | Indeterminada |
| Nacionalidade | Brasileira |
| Poder central | Deformação por Paradoxo |
| Artefato | O Lápis |
| Ameaça | Ômega, com limites rígidos |
| Status | Ativo |

Thaar'gon é uma anomalia consciente criada durante a formação do Universo Ø. A realidade tentou recriar Caio Almeida milhões de vezes. Cada falha deixou uma versão dele dentro da mesma consciência, até que o garoto deixou de ser uma pessoa única e se tornou um conjunto vivo de possibilidades incompatíveis.

Ele não destrói universos diretamente. Introduz uma única contradição em seus sistemas e observa as instituições, memórias, leis e relações se destruírem sozinhas. Sua filosofia afirma que toda realidade é um acordo e que todo acordo pode ser renegociado.

A ameaça de Thaar'gon não está em possuir todos os poderes. Ele possui uma regra: **introduzir paradoxos na realidade**. O custo é pago pelo próprio corpo, pelas memórias e pela duração limitada de sua existência. Em sua mão, um lápis escolar comum pode transformar uma frase em uma verdade temporária.
