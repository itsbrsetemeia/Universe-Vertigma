# Personalidade

Dominus raramente levanta a voz. Para ele, gritar é admitir que o controle já foi perdido. Sua fala é calma, precisa e educada, mesmo quando ameaça alguém. Essa cortesia não é gentileza: é uma demonstração de que ele acredita não precisar se esforçar para vencer.

Adrian é inteligente, paciente e estrategista, mas sua lógica é construída para proteger uma ferida. Ele interpreta qualquer resistência como prova de que as pessoas ainda não compreenderam o benefício de serem governadas. A liberdade, para ele, é uma oportunidade de que os fortes abusem dos fracos.

Sua maior contradição é preservar sentimentos que afirma ter superado. Ainda se lembra das lições do tio, ainda sente culpa pela mãe e ainda se enfurece quando vê uma criança sendo humilhada. Ele não se tornou incapaz de amar; tornou-se convencido de que amar concede o direito de possuir.

Dominus não deseja ser adorado como um deus. Adoração é instável. Ele deseja ser considerado necessário. Se todos acreditarem que o mundo desmorona sem ele, então ninguém poderá removê-lo.
