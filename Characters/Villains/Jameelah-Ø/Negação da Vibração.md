# Negação da Vibração

Jameelah-Ø possui um único poder central: **Negação da Vibração**. Ela identifica uma vibração e cria um Campo Ø que impede sua propagação por um meio específico.

Ela não absorve som. A vibração continua existindo, mas é impedida de atravessar o espaço, alcançar um receptor ou produzir uma consequência compartilhada.

Para usar o poder, Jameelah precisa identificar o fenômeno, definir o limite do campo e manter a negação com concentração contínua. Se perder o foco, a vibração retorna de uma vez, muitas vezes causando uma descarga.

| Regra | Limite |
|---|---|
| Meio | Ela precisa de um meio vibracional; o vácuo absoluto oferece nada para negar. |
| Escala | Áreas maiores exigem mais energia e aceleram a perda de memória. |
| Duração | Campos gigantes duram minutos, não horas. |
| Precisão | Negar uma frequência ou voz específica exige identificação exata. |
| Custo | Cada uso apaga memória, emoção ou habilidade sensorial. |
| Paradoxo | Para criar silêncio, ela precisa de uma vibração inicial. |

A força de Jameelah está na precisão conceitual, não em uma lista ilimitada de poderes.
