# Boi'Zhorrus — A Imperatriz da Agonia

> **“Eu não quero derrotar você. Quero que você me mostre quem realmente é quando tudo mais falha.”**

| Campo | Registro |
|---|---|
| Nome original | BoChun-Fu |
| Nome corrompido | Boi'Zhorrus |
| Títulos | A Imperatriz da Agonia; A Rainha dos Mil Combates; A Senhora do Dragão Negro; A General do Ø |
| Categoria | Vilã multiversal; guerreira transcendental |
| Realidade de origem | Universo Ø / D — Diálico |
| Idade biológica | 16 anos, congelada |
| Idade subjetiva | Indeterminada; milhares de anos no Reino dos Mil Combates |
| Origem cultural | Chinesa, da tradição marcial das Linhas de Pressão |
| Simbionte | Zhao |
| Ameaça | Ômega |
| Status | Ativa |

Boi'Zhorrus é uma guerreira transcendental que transformou o próprio trauma em doutrina. Presa no Reino dos Mil Combates, ela aprendeu a interpretar toda relação como uma arena e toda dificuldade como uma ferramenta de evolução.

Ela não busca matar adversários imediatamente. Quer descobrir o que sobra deles quando suas certezas, técnicas e orgulho deixam de funcionar. O problema é que Boi'Zhorrus projeta sua própria incapacidade de viver em paz sobre todos que encontra.

Seu poder vem de Zhao, uma entidade energética do Universo Ø que se manifesta como um dragão, mas não é um animal nem um simples avatar. Zhao é um simbionte faminto que oferece força em troca de presença. Cada batalha aproxima os dois e ameaça apagar BoChun-Fu.
