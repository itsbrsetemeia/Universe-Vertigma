# Baralho Arcano

O Baralho Arcano é um conjunto de cartas mágicas capazes de armazenar, traduzir e manifestar conceitos sobrenaturais. Cada carta é um selo, não apenas um recipiente de energia. Quando Aurora saca uma carta, o símbolo se acende e a magia correspondente é liberada.

Aurora pode invocar o Baralho quando quiser, mas não escolhe qual carta receberá. Ela escolhe abrir a possibilidade; o Baralho escolhe a manifestação. A escolha parece responder às circunstâncias, ao estado emocional de Aurora e a uma lógica que ainda não foi decifrada.

| Carta | Função principal |
|---|---|
| Chama | Manipulação de fogo e calor |
| Gelo | Congelamento e controle de frio |
| Trovão | Descargas e condução elétrica |
| Espelho | Reflexão ou desvio de ataques |
| Véu | Intangibilidade e ocultação parcial |
| Portal | Teletransporte e abertura de passagens |
| Legião | Criação de duplicatas temporárias |
| Gravidade | Alteração de peso e atração |
| Eclipse | Manipulação de sombras |
| Cura | Regeneração e restauração limitada |
| Vazio | Energia de ausência e anulação parcial |
| Tempo | Interferência temporal extremamente limitada |

Aurora normalmente usa uma carta por vez. Combinar cartas é possível, mas aumenta o consumo mágico e cria efeitos difíceis de prever. Fogo e vento podem criar uma tempestade de chamas; gelo e gravidade podem formar uma prisão cristalina; eletricidade e portal podem transportar uma descarga para outro ponto.

O Baralho também possui uma consciência instintiva. Algumas cartas surgem quando Aurora realmente precisa delas; outras aparecem justamente para obrigá-la a encontrar uma solução que não esperava.
