# Kael Moreau — Paradoxo

> **“Se o amanhã me negar uma resposta, eu aprendo a fazer outra pergunta.”**

| Campo | Registro |
|---|---|
| Nome completo | Kael Moreau |
| Codinomes | Paradoxo, Dado Vivo, Variável, Caos, Inconstante, Dia Zero |
| Categoria | Portador; herói |
| Herança | Roda do Destino |
| Origem | Humana e metafísica |
| Afiliação | Portadores |
| Universo | V-202 — Universo Principal |
| Idade | 20 anos |
| Nacionalidade | Franco-canadense |
| Tema | Incerteza, preparação e liberdade |

Kael Moreau é um Portador cuja Herança muda completamente todos os dias, exatamente à meia-noite. Ele desperta conhecendo apenas o nome do poder que recebeu. O alcance, o custo, as aplicações e as fraquezas precisam ser descobertos antes que o dia termine.

A **Roda do Destino** nasceu do último desejo de sua avó, uma estatística fascinada pela incerteza: **“A vida nunca segue os nossos planos. Aprenda a vencer com o que ela colocar nas suas mãos.”** A Herança não concedeu a Kael um poder específico. Concedeu a ele a obrigação de se reinventar.
