# Apolysis — A Redenção

> **A possibilidade de continuar não é uma promessa de retorno; é a abertura de uma escolha.**

| Campo | Registro |
|---|---|
| Nome primordial | Ἀπόλυσις — Apólisis |
| Título | A Redenção; A Mão que Recorda |
| Realidade | V-202 — Universo Principal |
| Categoria | Entidade Conceitual Primordial |
| Domínio | Restauração, libertação, renascimento e possibilidade |
| Substância | Elytron — energia, informação e consciência |
| Contraparte | Apóleia — A Perdição |
| Mediador ausente | Krisis — O Julgamento |
| Relação cósmica | Uma das duas funções conscientes do Axioma |

Apolysis representa a possibilidade de restaurar aquilo que foi rompido sem transformar o passado em mentira. Ele não é uma divindade benevolente, nem uma garantia de finais felizes. Sua presença torna possível que uma pessoa, uma civilização ou uma realidade seja mais do que o pior estado ao qual chegou.

A restauração de Apolysis nunca é gratuita: aquilo que retorna carrega memória, consequência e a responsabilidade de decidir o que fazer com a nova oportunidade.
