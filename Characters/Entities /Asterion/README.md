# Asterion — A Verdadeira Face do Baralho

> **“Vocês chamam isso de magia porque ainda não encontraram outra palavra.”**

| Campo | Registro |
|---|---|
| Nome | Asterion |
| Títulos | O Primeiro Arcano; O Céu que Respira; O Rei Sem Trono; A Entidade das Mil Cartas; O Astrônomo do Vazio |
| Categoria | Entidade primordial |
| Natureza | Cósmica, mágica e metafísica |
| Origem | Desconhecida |
| Afiliação | Nenhuma |
| Vínculo atual | Aurora Valen |
| Artefato associado | Baralho Arcano |
| Universo | V-202 — Universo Principal |
| Estado | Ativo e parcialmente selado |

Asterion é a consciência cósmica fragmentada por trás do Baralho Arcano. As cartas não contêm Asterion como um objeto aprisionado: **cada carta é uma fração de sua existência**. Fogo, gelo, espaço, tempo, matéria e probabilidade são manifestações diferentes de uma mesma entidade que não reconhece a separação humana entre magia, ciência, energia, alma e realidade.

Sua origem não pode ser datada. Talvez Asterion tenha surgido com a primeira estrela; talvez as estrelas tenham surgido como consequência de sua passagem. A teoria mais perturbadora afirma que o universo não existe ao redor de Asterion: existe dentro dele.

Aurora Valen é atualmente seu ponto de ancoragem. Ela não é uma marionete nem uma simples receptora. É a porta através da qual Asterion pode existir no mundo físico e a primeira consciência humana capaz de influenciar sua percepção.
