# Apóleia — A Perdição

> **O fim não é o oposto da existência; é o limite que dá peso a tudo que existe.**

| Campo | Registro |
|---|---|
| Nome primordial | Ἀπώλεια — Apóleia |
| Título | A Perdição; A Última Testemunha |
| Realidade | V-202 — Universo Principal |
| Categoria | Entidade Conceitual Primordial |
| Domínio | Perda, ruína, extinção, consequência e fim |
| Substância | Ananké — lei primordial condensada |
| Contraparte | Apolysis — A Redenção |
| Mediador ausente | Krisis — O Julgamento |
| Relação cósmica | Uma das duas funções conscientes do Axioma |

Apóleia representa a necessidade de que algumas coisas terminem de modo real. Ela não é uma vilã cósmica, uma deusa da morte ou uma força de destruição aleatória. Sua função é impedir que a existência seja aprisionada numa restauração infinita, onde nenhuma consequência permanece e nenhum encerramento é respeitado.

Quando atua, ela não pergunta apenas o que pode destruir. Pergunta se a continuidade ainda possui fundamento ou se se tornou uma repetição que devora o futuro.
