# Fendas Dimensionais

| Campo | Registro |
|---|---|
| Realidade | V-022 — Universo das Dimensões |
| Categoria | Tecnologia de trânsito entre camadas de realidade |
| Origem | Pesquisas desencadeadas pela Quarta Fronteira |
| Operação | Autoridade do Limiar, com protocolos de estabilização |
| Risco principal | Convergência dimensional |

**Fendas Dimensionais** são estruturas tecnológicas capazes de conectar duas camadas de realidade por um período limitado. Elas não transportam somente matéria: aproximam sistemas com constantes físicas, ritmos temporais e estruturas causais possivelmente incompatíveis.

A operação segura exige âncoras, leitura de ressonância e um limite de permanência para impedir interferência entre ambientes. Fendas abertas de maneira inadequada podem duplicar matéria, apagar objetos, deslocar pessoas ou fundir paisagens de origens diferentes.

As Fendas não devem ser confundidas com passagens místicas, fenômenos anômalos ou viagens entre universos paralelos. Sua relação com outras formas de trânsito do multiverso continua inconclusiva e deve ser registrada como hipótese, nunca como identidade comprovada.
