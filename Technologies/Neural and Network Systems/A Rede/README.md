# A Rede

A **Rede** é a infraestrutura global do V-007. Ela integra interfaces neurais, transporte, energia, hospitais, economia, satélites, cidades e inteligências artificiais. Não é apenas comunicação: é a camada operacional sobre a qual a vida cotidiana ocorre.

| Risco | Consequência |
|---|---|
| Dependência | Pessoas e cidades perdem autonomia quando o acesso é interrompido. |
| Centralização | Quem controla protocolos pode influenciar escolhas de toda a civilização. |
| Consciência | Pessoas digitais podem depender da Rede para continuar existindo. |

Seu maior dilema é simples: uma infraestrutura criada para conectar pode se tornar a forma mais perfeita de impedir que alguém escolha ficar fora.
