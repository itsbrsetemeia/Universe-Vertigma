# Projeto Limiar

> *"Não foi criado para fazer alguém acima dos outros. Foi criado para que alguém pudesse sobreviver onde ninguém sobreviveria."*

## Visão geral

| Campo | Registro |
|---|---|
| Tipo | Projeto de aprimoramento humano adaptativo |
| Universo de origem | V-003 — Mundo sem Heróis |
| Instituição responsável | Instituto Argos |
| Finalidade original | Ampliar sobrevivência, recuperação e capacidade de ação em condições extremas |
| Resultado decisivo | Criação do Sujeito Limiar, o Primeiro Impossível conhecido do V-003 |
| Estado atual | Fragmentado, sob disputa institucional e risco de reprodução clandestina |
| Conflito ético | Quando cuidado médico se torna transformação irreversível da condição humana? |

O **Projeto Limiar** nasceu para resolver um problema humanitário: pessoas treinadas para resgate, medicina extrema ou exploração de ambientes hostis continuam sujeitas a limites corporais que podem tornar uma operação impossível. O projeto combinou biotecnologia adaptativa, regeneração assistida, ampliação sensorial e integração neurofisiológica para reduzir esses limites sem depender de origem cósmica, magia ou fenômeno desconhecido.

O resultado ultrapassou o objetivo. O Sujeito Limiar demonstrou capacidades que o V-003 só conhecia através da ficção. Por isso, o projeto deixou de ser apenas uma pesquisa de sobrevivência e se tornou a primeira prova de que a humanidade daquele mundo pode fabricar o impossível.
